# Results

This folder contains the performance analysis, testing observations, and final validation records of the **Team Falcons E-Kart**.

## 🏎️ Project Validation

The E-Kart development process included:

1. Vehicle requirement study
2. CAD modelling
3. Structural analysis
4. Component selection
5. Fabrication
6. Assembly and wiring
7. Testing and troubleshooting
8. Performance validation
9. Final optimization

## 🔬 Chassis Analysis

The chassis was analysed using **ANSYS Workbench** with a documented applied load of **3000 N**.

| Load Case | Total Deformation |
|---|---:|
| Front | 1.0008 mm |
| Rear | 0.897 mm |
| Side | 0.616 mm |
| Roll-over | 0.214 mm |

The presentation also records the corresponding factor-of-safety values for these cases.

## ⚡ Powertrain

The final powertrain configuration includes:

- 5 kW PMSM
- 60 V nominal electrical system
- DATAI PMSM controller
- 60 V, 90 Ah NMC lithium-ion battery
- Chain drive
- 4:1 final drive ratio

## 🛞 Steering Validation

- Ackermann Percentage: 37.5%
- Turning Radius: 2.7 m
- Mechanical Linkage Ratio: 10:1

## 🛑 Braking System

- Rear disc brake
- Disc Diameter: 220 mm
- Disc Thickness: 4.0 mm
- Brake Pedal Ratio: 4–5:1
