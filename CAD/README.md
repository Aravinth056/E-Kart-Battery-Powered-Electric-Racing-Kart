# CAD Design

## 📌 Overview

This folder contains the CAD design and analysis documentation of the **Team Falcons E-Kart**.

The 3D chassis model was developed using **SolidWorks**, followed by structural analysis using **ANSYS Workbench** to evaluate strength and deformation.

---

## 🛠️ Design Methodology

```text
Vehicle Requirements
        ↓
Initial Chassis Layout
        ↓
Hand Sketches
        ↓
3D CAD Modelling – SolidWorks
        ↓
Structural Analysis – ANSYS Workbench
        ↓
Design Optimization
        ↓
Final Assembly & Fabrication
