# E-Kart – Battery-Powered Electric Racing Kart

## Project Overview

Team Falcons developed an electric racing kart for the E-Kart competition.

The project focused on:

- Electric vehicle design
- Chassis design and fabrication
- Motor and battery selection
- Power transmission
- Steering and braking
- Electrical integration
- Safety
- Testing and performance validation

## Vehicle Specifications

| Parameter | Specification |
|---|---|
| Motor Category | 5 kW |
| Motor Type | PMSM |
| Motor Voltage | 60 V DC |
| Maximum Design RPM | 3800 RPM |
| Peak Torque | 58 Nm |
| Battery | Lithium-ion |
| Battery Voltage | 60 V nominal |
| Battery Capacity | 90 Ah |
| Battery Chemistry | NMC |
| Drive Ratio | 4:1 |
| Chassis Material | AISI 4130 |
| Overall Length | 1700 mm |
| Wheelbase | 1100 mm |
| Ground Clearance | 50 mm |

## Chassis

The chassis was designed using SolidWorks and analyzed using ANSYS Workbench.

The selected chassis material was AISI 4130 steel.

Main material properties:

- Density: 7850 kg/m³
- Young's Modulus: 205 GPa
- Yield Strength: 435 MPa
- Ultimate Tensile Strength: 560 MPa
- Tube Outer Diameter: 25.4 mm
- Tube Thickness: 1.6 mm

## Powertrain

The kart uses a 5 kW PMSM motor with a chain-drive transmission.

- Motor sprocket: 12 teeth
- Final sprocket: 48 teeth
- Final drive ratio: 4:1
- Drive shaft: 25 mm
- Keyway: 8 × 7 mm

## Battery

The kart uses a 60 V nominal lithium-ion battery pack.

- NMC chemistry
- 90 Ah capacity
- 16S × 30P configuration
- BMS protection
- Passive air cooling
- 67.2 V fully charged voltage

## Steering and Braking

The steering system uses mechanical linkage with Ackermann geometry.

The braking system includes:

- Rear disc brake
- 220 mm disc diameter
- 4 mm disc thickness
- 4–5:1 brake pedal ratio

## Electrical System

The kart uses separate high-voltage and low-voltage systems.

### High Voltage System

Used for:

- Battery
- Motor controller
- PMSM motor
- High-power wiring

### Low Voltage System

Used for:

- Sensors
- Dashboard
- Relays
- Auxiliary systems
- Safety indicators

Safety components include:

- Kill switches
- Accumulator Isolation Relay
- Manual service disconnect
- TSAL indicator
- RTDS buzzer
- Fuse and MCB protection
- BMS
