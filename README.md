# E-Kart: Battery-Powered Electric Racing Kart

## 📌 Project Overview

A battery-powered electric racing kart prototype designed and built for participation in the **AIMS E-Kart competition**.

The project focused on electric vehicle development, component selection, manufacturing, fabrication, assembly, testing, and tuning.

---

## 🎯 Objective

To design and build a competition-ready battery-powered electric racing kart prototype with a focus on practical manufacturing and vehicle assembly.
